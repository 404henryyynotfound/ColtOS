# ColtOS

A lightweight, single-file browser-based desktop operating system **built for Muir Middle School (HVS)** by **Henry Green**. Serving as the flagship hub of the **ColtApps** suite, **ColtOS** brings multitasking windows, a file manager, terminal, study notes, and built-in launchers for **ColtBrowser** and **ColtEmulate** together in one fast, Chromebook-friendly workspace.

---

## Quick Access

### For HVS Students (No Download Required)
- **ColtOS Web Desktop:** [sites.google.com/hvs.org/coltos](https://sites.google.com/hvs.org/coltos)

*(Must be signed into your HVS Google account to access the Google Sites portal.)*

### Download & Run Locally (Downloads Folder)
1. Click the **Code** button on this repository and select **Download ZIP** (or download `coltos.html` directly).
2. Open your computer's **Downloads** folder and extract the ZIP file if needed.
3. Double-click `coltos.html` to boot ColtOS directly in any modern web browser—no installation or internet setup required.

## Features & Built-In ColtApps

- **Window Manager & Taskbar:** Draggable, resizable frosted-glass windows with minimize/maximize/close controls, running app indicators, a searchable **Start Menu**, a Lock Screen, and a System Tray with a live clock and Focus Mode.
- **ColtBrowser:** Multi-tab DuckDuckGo Instant Answer search and web viewport with HVS study bookmarks and quick links to ColtBrowser Standard and LITE.
- **ColtEmulate:** Integrated cross-OS binary inspector and hypervisor preview for `.exe`, `.dmg`, `.iso`, and `.rom` files.
- **ColtNotes:** Persistent Markdown editor with word/character counters, `.md` file export, and an automatic **Flashcard Quiz Mode** built from bullet points.
- **ColtFiles:** Virtual `/home/muir-student` file explorer (`Documents`, `Downloads`, `Apps`, `Projects`) that opens notes in ColtNotes and binaries in ColtEmulate.
- **ColtTerminal:** Interactive command-line shell supporting `help`, `ls`, `neofetch`, `date`, `calc`, `open <app>`, and `clear`.
- **ColtSettings:** Customize desktop wallpapers (*Muir Colts Navy & Gold*, *Midnight Cyber*, *Alpine Dawn*, *Aurora Slate*), accent colors, glass opacity, and top/bottom taskbar position.
